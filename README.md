# InvoiceGen

A desktop invoice generator built with C# and WPF.

## Features

- Add multiple invoice items
- Automatic item total calculations
- Customer name and address fields
- Invoice preview using a DataGrid
- PDF invoice generation
- Save invoices as PDF files

## Built With

- C#
- WPF / XAML
- QuestPDF

## Status

Currently in development. Additional UI improvements, invoice customization, and item management features are planned.
